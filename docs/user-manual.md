## 1. はじめに

### 1.1 KIZAMI DJ でできること

- 自分の音楽ファイルを取り込み、BPM（曲の速さ）・キー（調）・拍の位置を自動で解析する。
- 2台のデッキ（A / B）で曲を再生し、ミキサーで音量・音色を調整してつなぐ。
- ループ、Hot Cue（好きな位置に印を付けて即ジャンプ）、Beat Jump（拍単位のジャンプ）、SYNC（BPM を合わせる）を使う。
- Beat FX（エコー・リバーブなど）をかける。
- ヘッドホンで次の曲を先に聴く（CUE。4ch 出力の機器が必要）。
- ミックスを WAV ファイルに録音する。
- キーボード、または MIDI コントローラーで操作する。

### 1.2 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows（録音の保存先などが Windows 専用の処理で作られています）。対応バージョンの一覧は未確認 |
| 読み込める曲の形式 | MP3・AAC（M4A）・FLAC・WAV・AIFF・ALAC |
| ヘッドホン CUE | 4ch 出力（3-4ch がヘッドホン）の機器が必要 |
| 画面の波形 | WebGL2 が使える環境が必要 |
| 拍の解析（AI） | Beat This! のモデルを置いたときだけ AI を使う。無いときは簡易の推定器（8.1 参照） |
| 必要な PC の性能（CPU・メモリなど） | 未確認 |

### 1.3 起動と最初の準備

1. KIZAMI DJ を起動します。「KIZAMI DJ / Starting…」が出て、少し待つとメイン画面になります。
2. ライブラリの空の画面で **[Add Folder]** を押し、音楽のフォルダを選びます。取り込みと解析が自動で始まります（3 章）。
3. 設定（右上の ⚙）で出力デバイスを確かめます（8.1）。
4. 曲を行ごとデッキへドラッグして読み込み、PLAY を押します（4 章）。

起動に失敗したときは、復元の画面が出ます（8.4）。

#### 初回起動の利用許諾

初めて起動したときは、メイン画面の前に「License Agreement」（利用許諾）の画面が出ます。内容を読んで **[Accept]** を押すと、同意した文面の版が設定に保存され、以降の起動では出ません。**[Decline]** を押すとアプリが終了します（何も保存されないので、次に起動したときにもう一度この画面が出ます）。同意するまでは、画面の操作もキーボードのショートカットも使えません。ただし、MIDI コントローラーの操作は、この版では同意待ちの間も届きます。利用許諾の文面が改められた版では、同意済みの方にも起動時にもう一度同意をお願いします。

│ バナー（赤。問題があるときだけ出る）                      │

│ 拡大波形 B                                                │
├──────────────┬──────────────────┬─────────────────────────┤
│ デッキ A     │ ミキサー         │ デッキ B                │
│ （全体波形） │ TRIM/EQ/FILTER   │ （全体波形）            │

- ウィンドウが低いときは、縦にスクロールします。
- デッキの色は A がピンク、B が水色です。
- 設定・復元の画面・起動中・MIDI Learn 中は、キーボードショートカットが止まります。

### 2.1 画面上部（TopBar）

| 表示 | 意味 |
|---|---|
| Master {BPM} | マスターデッキの BPM |
| ● REC | 録音の開始／停止（Ctrl+R）。録音中は経過時間が出る。「⚠ Dropped {x}」は、書き込みが追いつかず欠けた時間（7 章） |
| CPU バー | 音の処理にかかった時間（バッファの時間に対する割合）。70% 超で警告色、90% 超で危険色 |
| ⚠ n | アンダーラン（音切れ）の回数 |
| CLIP / ⚠ CLIP | リミッターの手前で 0 dB を超えると 1 秒点灯 |
| GR | リミッターが音量を下げた量 |
| MIDI Learn active [Exit] | MIDI Learn のあいだだけ出る（8.3） |
| ⚙ | 設定を開く |

TopBar と赤いバナーの下には、新しい版があるときのアップデート通知の帯が出ることがあります（2.2）。

### 2.2 アップデート通知

更新は通知のみで、**[Update]** を押したときだけ入ります。

| 表示 | 意味・操作 |
|---|---|
| 「Version {版} is available」＋ **[Update]** / **[Later]** | 新しい版があります。**[Update]** で更新を始めます。**[Later]** を押すと、その版の通知は次の起動まで出ません。補足の文には更新内容の説明が出ます（なければ「Updating will restart the app」＝更新するとアプリが再起動します） |
| 「Installing update ({版})」 | 更新を入れています。「The app will restart when it finishes. Please wait.」と出るので、終わってアプリが再起動するまで待ちます |
| 「Could not check for or apply the update」 | 更新の確認、または更新を入れることに失敗しました。理由が同じ帯に出ます。入れるのに失敗したときは、更新は残るので、もう一度押せます |

## 3. ライブラリ

曲を管理する画面です。左にフォルダ・プレイリストのツリー、右に曲一覧があります。

### 3.1 取り込み（フォルダ）

- ツリーの「Folders」の横の **＋**、または空のライブラリ（「Your library is empty. Add a music folder to start importing and analyzing.」）の **[Add Folder]** で音楽のフォルダを追加します。
- 曲を数本だけ入れたいときは、「Folders」の横の **♪＋** で音声ファイルを選びます（複数選べます）。選んだ曲だけが取り込まれ、そのフォルダは監視の対象になりません。エクスプローラーからのドラッグ＆ドロップには未対応です。
- 追加すると取り込みが始まり、「Importing done / total」・進捗バー・**[Cancel]** が出ます。
- 終わると「Import finished」と「Added n, skipped n, failed n」が出ます。中止すると「Import cancelled」。
- 登録済みのフォルダと、その中や外のフォルダは重ねて登録できません。
- フォルダを外すには、設定の「General」タブで **[Remove]**（8.1）。外してもライブラリから除くだけで、曲のファイルは消えません。

### 3.2 ツリー

| 項目 | 内容 |
|---|---|
| All Tracks (n) | 全曲を表示 |
| Folders | 登録したフォルダごとに絞り込む |
| Playlists | 常に表示される（プレイリストがまだ無くても見出しは出る）。プレイリストのフォルダごとに字下げされる |
| rekordbox | rekordbox の XML を取り込む（3.2.2） |

#### 3.2.1 プレイリストの編集

- 「Playlists」の横の **＋** で新しいプレイリスト、**📁** でプレイリストのフォルダを作ります。名前を入力して Enter（Esc で取り消し）。
- 行にカーソルを乗せると **✎**（名前を変える。F2 でも可）と **🗑**（削除。Delete でも可）が出ます。削除は確認が出ます。曲そのものは消えません。
- ツリーのプレイリストやフォルダの行をドラッグし、別のフォルダの行に落とすと、その中へ移せます。プレイリスト欄の余白に落とすと一番上へ出ます。自分自身や自分の中身の下には移せません。
- 曲一覧の行をツリーのプレイリストへドラッグすると、末尾へ追加します（同じ曲を何度でも入れられます）。
- プレイリストを並び順で開いている間は、行のドラッグで順番を入れ替え、行の操作で曲を外せます（曲そのものは消えません）。

曲一覧の上のツールバーでも操作できます。

| 部品 | 内容 |
|---|---|
| Add to playlist（選択欄） | 曲一覧で選んだ曲を、選んだプレイリストの末尾へ足す。選択欄の初期表示は「Choose…」で、プレイリストが無いときは「(No playlists)」。曲を選んでいないとき、またはプレイリストが無いときは使えない。足し先に選べるのはプレイリストだけで、プレイリストのフォルダは選べない |
| **[↑ Up]** / **[↓ Down]** | 選んだ曲を1つ上／下へ動かす。プレイリストを開いているときだけ出る。先頭の曲では Up、末尾の曲では Down が押せない |
| **[Remove from playlist]** | 選んだ曲をプレイリストから外す（曲そのものは消えません）。プレイリストを開いているときだけ出る |

- 並べ替え（Up / Down、行のドラッグ）と Remove は、検索ボックスが空で、プレイリストの並び順のまま開いているときだけ使えます。使えないときは、3つのボタンが押せなくなり、「Reordering works only with an empty search while viewing in playlist order」と出ます。

#### 3.2.2 rekordbox の XML を取り込む

- ツリーの「rekordbox」の **[Import…]** で、rekordbox から書き出した XML を選びます。
- 確認に出る **「Overwrite existing cues and manually edited values with the XML contents」** は、初期状態ではオフです。オフなら、すでにあるキューと手で直した拍・キーはそのままで、足りないものだけが入ります。オンなら XML の内容で置き換えます。
- 終わると、追加した曲・プレイリスト・キューの数が通知に出ます。見つからないファイルがあれば、その件数も出ます。
- AAC（m4a など）の曲は、書き出し元との先頭のずれ（約 34 ミリ秒）を自動で補正して拍の位置を入れます。

### 3.3 検索

- 検索ボックス（Ctrl+F で移動）に入力すると、入力をやめて 150 ミリ秒後に検索します。Enter で即検索します。
- Esc で検索ボックスから出ます。日本語入力の変換中でも誤動作しません。

### 3.4 並べ替え

- 列の見出しをクリックすると、その列で並べ替わります。もう一度クリックすると逆順です。

### 3.5 列の意味

| 列 | 意味 |
|---|---|
| （デッキ列） | その曲が載っているデッキ（下の「曲一覧の見かた」） |
| Title / Artist | 曲名・アーティスト |
| BPM | 曲の速さ（1 分間の拍の数）。未解析は「—」 |
| Key | 曲の調。Camelot 表記（下の「キーの表記」）。未解析は「—」 |
| Time | 曲の長さ |
| Rating | ★/☆（5 段階）で表示。クリックしても変えられません（表示のみ） |

- 表示は最大 1000 曲です。超えると「Showing the top 1000 tracks. Narrow down with search.」と出ます。
- 行をクリックすると選択、ドラッグするとデッキへ読み込めます（4.1）。

### 3.6 解析と行の状態

曲を取り込むと、BPM・キー・拍の位置が自動で解析されます。

| 表示 | 意味 | することは |
|---|---|---|
| ⏳（解析待ち・解析中） | 解析の順番待ち、または解析中 | 待つ |
| ⚠（解析に失敗）＋ **[Re-analyze]** | 解析に失敗した | **[Re-analyze]** を押す |
| (missing) | ファイルが移動・削除された。行はドラッグできない | 元の場所へ戻すか、フォルダを登録し直す |

- 「Automatic analysis stopped」「{n} analyses timed out. You can still use [Re-analyze] on each track」と出たときは、自動解析が止まっています。曲ごとの **[Re-analyze]** は使えます。
- 解析できない曲でも、デッキに読み込んで再生はできます。ただし拍の解析がないと SYNC・ループ・Beat Jump は使えません（4.8）。

### 3.7 曲一覧の見かた

#### デッキ列（A / B）

- 曲名の左の列に、その曲が載っているデッキを出します。デッキAはピンク、デッキBは水色の文字です。
- 再生中は「▶A」のように▶が付き、太字で光ります。ロードしただけで止まっているときは、色付きの文字と枠だけです。
- 同じ曲を両方のデッキに載せたときは、A と B が両方出ます。
- 載っている曲の行は、左端にデッキ色の帯が付き、曲名が太字になります。
- 表示の補足：マウスを載せると「Playing on Deck A」「Loaded on Deck A」と出ます。

#### ★印（キーが合う曲）

- マスターデッキの曲と、キー（Camelot 表記）が合う曲の頭に★が付きます。ミックスしたときに音が合いやすい曲の目印です。★の行は、曲名とキーの欄が緑色になります。
- 「マスター」は、BPM とキーの基準にしているデッキです。マスターが切り替わると、★も付け替わります。
- ★にマウスを載せると「Compatible with the master key」と出ます。

##### キーの表記（8A・8B など）について

曲の「キー」欄の「8A」「7B」などは、曲の調（音階）を表す **Camelot ホイール**という記号です。DJ が曲のつなぎやすさを見分けるために使います。

- 数字（1〜12）は、調を5度ずつ並べた円（キーの輪）の位置です。時計の文字盤のように 12 の次は 1 に戻ります。
- 文字は、A が短調（マイナー・暗めの響き）、B が長調（メジャー・明るい響き）です。
- 例：8A = イ短調（Am）、8B = ハ長調（C）。7A = ニ短調（Dm）、9A = ホ短調（Em）。
- 輪の上で隣り合う調や、同じ番号の A/B は、音が混ざっても濁りにくく、つなぎやすい関係です。

##### ★が付く条件

マスターのキーと、次のどれかの関係にある曲に付きます。

| 条件 | マスターが 8A のとき |
|---|---|
| 同じキー | 8A |
| 同じ番号で A/B だけ違う（相対調） | 8B |
| 同じ A/B で番号が ±1（12 と 1 は隣） | 7A、9A |

- 例：マスターが 8A なら、★が付くのは 8A・8B・7A・9A の4種類です。マスターが 12A なら、12A・12B・11A・1A です。
- 番号が ±1 でも A/B が違うもの（7B、9B など）や、番号が 2 以上離れたキーには付きません。
- マスターの曲自体も、キーが同じなので★が付きます。

##### ★が付かない場合

- マスターデッキに曲が載っていない。
- マスターの曲のキーが未解析。
- その曲のキーが未解析、または「1A」〜「12B」の形式でない。

（実装：`ui/src/lib/camelot.ts` の `isCompatibleKey`）

## 4. デッキ

画面の左右にある 2 台のデッキ（A / B）の使い方です。

### 4.1 曲を読み込む

| 方法 | 操作 |
|---|---|
| ドラッグ | ライブラリの曲の行をデッキへドラッグ |
| ショートカット | ライブラリで曲を選び、Shift+←（デッキ A）／ Shift+→（デッキ B） |

- 空のデッキには「No track loaded (drag one from the library, or press Shift+←)」と出ます（B は Shift+→）。
- 読み込み中は「Loading…」。失敗すると原因と対処が出ます。
- 全体波形は、先頭から先に読み込む 2 段階の読み込みです。まだ読み込んでいない部分は暗く表示されます。
- 見つからないファイルは読み込めません。

### 4.2 デッキの表示

- 見出し：デッキ名・曲名・アーティスト。マスターのデッキには「MASTER」、自動でマスターになっているときは「MASTER (auto)」と出ます。
- 表示：BPM、キー、経過時間、残り時間（−付き）。「⏳ Analyzing」「⚠ Analysis failed」も出ます。

### 4.3 再生・停止・CUE

| ボタン | 動き |
|---|---|
| PLAY（▶ / ❚❚） | 再生／一時停止 |
| CUE | 止まっているときは、いまの位置に Cue 点を置く。押している間だけ鳴り、離すと Cue 点へ戻る（ホールド式） |
| SYNC | 相手デッキの BPM に合わせる（4.7）。拍の解析がないと押せない |
| M | このデッキをマスターにする。もう一度押すとマスターを自動に戻す |

### 4.4 Hot Cue

曲の好きな位置に印を付けて、すぐにそこへ飛べる機能です。各デッキに 1〜8 の 8 個あります。

| 状態 | 操作 | 動き |
|---|---|---|
| 空き | 押す | いまの位置を記録 |
| 記録済み | 押す | その位置から再生（押している間のホールド式） |
| 記録済み | Shift+押す | 削除 |

- ボタンにマウスを載せると、位置とキーが出ます。

### 4.5 ループ

指定した区間をくり返し再生します。拍の解析が必要です。

| 操作 | 内容 |
|---|---|
| オートループ ½ / 1 / 2 / 4 / 8 | その拍数のループを、いまの位置から作る |
| ½× / 2× | 作ったループの長さを半分／倍にする |
| IN / OUT | 手動でループの始まり／終わりを指定する。IN を押すと「waiting for OUT」の状態になる |
| ⟲ | ループを終える。「waiting for OUT」のときは Loop In を取り消す |
| SLIP | 入れておくと、ループやスクラッチの間も裏で再生位置が進み、終わるとその位置へ復帰する |

### 4.6 Beat Jump

- ◀◀ ▶▶ で、選んだ拍数ぶん戻る／進みます。拍数は 1 / 2 / 4 / 8 / 16 から選びます（初期値は 4）。
- 拍の解析が必要です。キーボードの Beat Jump も、この画面で選んだ拍数を使います。

### 4.7 テンポとピッチ、SYNC、マスター

用語：**テンポ**は曲の再生速度、**ピッチ**は音の高さです。ふつう速度を変えると音の高さも変わります。

- **TEMPO フェーダー**（デッキの外側の縁。A は左、B は右）：下に動かすと速く（+）、上で遅く（−）。ダブルクリックで 0%。
- 現在の値が % で出ます。レンジのボタンを押すごとに ±8% → ±16% → ±50% と切り替わります。
- **KEYLOCK**：テンポを変えても音の高さを保ちます。
- **BEND**：ジョグ（MIDI コントローラー）で一時的に速さをずらしているとき、「BEND +x.x%」と出ます。
- **SYNC**：相手デッキの BPM に自動で合わせます。拍の解析が必要です。
- **マスター**：BPM とキーの基準にするデッキ。M ボタンで手動指定、解除すると自動に戻ります。★印（3.7）の基準にもなります。

### 4.8 拍の解析がないとき

デッキに「⚠ No beat grid analysis(SYNC, loops and Beat Jump are unavailable)」と出ます。曲の解析が終わっていないか失敗しています。ライブラリで **[Re-analyze]**（3.6）を試してください。

### 4.9 波形

| 波形 | 内容 |
|---|---|
| 拡大波形（画面上部） | 再生位置を中央に置いた 8 秒ぶん。拍のグリッド・ループ・Cue・Hot Cue が重なって出る |
| 全体波形（デッキ内） | 曲全体。クリックするとその位置へ移動する |

- WebGL2 が使えないと「Cannot display the waveform (WebGL2 is unavailable)」、描画に失敗すると「Cannot display the waveform (drawing failed)」と出ます。

## 5. ミキサー

画面中央のミキサーは、2 つのチャンネル（A / B）と共通部分でできています。

### 5.1 つまみ・フェーダーの操作

| 操作 | 動き |
|---|---|
| 縦にドラッグ | 値を変える（約 200px で全範囲） |
| Shift+ドラッグ | 細かく変える |
| ← ↑ → ↓ | 一定量ずつ変える（Shift で細かく） |
| Home / End | 最小／最大 |
| ダブルクリック、Delete、Backspace | 初期値に戻す |
| Alt+クリック、または EQ でフォーカス中に Enter | KILL（5.3）の入／切 |

### 5.2 TRIM とオートゲイン

- **TRIM**：入力の音量を調整するつまみ（±12 dB）。曲ごとの録音レベルの差を揃えるために使います。ダブルクリックで 0 dB。
- 「Auto x dB」はオートゲインの補正量です。オートゲインは曲の音量を −14 LUFS（人が感じる音量の単位）に揃える機能で、設定で入／切できます（8.1）。TRIM は手動の調整で、自動の補正に重ねて効きます。

### 5.3 EQ（HI / MID / LOW）と KILL

- **EQ**：音を高音（HI）・中音（MID）・低音（LOW）に分けて、それぞれ上げ下げします。範囲は −40 dB 〜 +6 dB。ダブルクリックで 0 dB。
- **KILL**：その帯域を完全に切ります。「KILL」と表示されます。もう一度 Alt+クリックで戻ります。

### 5.4 FILTER

- 1 つのつまみで 2 種類のフィルターを切り替えます。左に回すと LPF（ローパス＝高音を削る）、右に回すと HPF（ハイパス＝低音を削る）。中央が OFF です。
- 表示は「LPF n%」「HPF n%」「OFF」。ダブルクリックで OFF。

### 5.5 チャンネルフェーダー（VOL）とメーター

- VOL フェーダーで、チャンネルの音量を調整します（%表示）。横のメーターはピークを表示します。
- メーターは −48 dBFS から。−6 dB を超えると警告色、−0.3 dB を超えると危険色（音割れ寸前）になります。

### 5.6 CUE（ヘッドホン）

- 各チャンネルの **CUE A / CUE B** ボタンで、そのチャンネルをヘッドホンで聴けます（本番の音には出ません）。
- 4ch 出力の機器でないと使えません。使えないときはボタンが押せず、「No headphone output (channels 3-4)」と出ます。

### 5.7 クロスフェーダー（X-FADER）

- 左右に動かして A と B の音量を切り替えます。表示は「CENTER」または「A n%」「B n%」。ダブルクリックで中央。
- カーブ（なめらか／カット）は設定で変えられます（8.1）。

### 5.8 MASTER

- 縦のフェーダーで、出力全体の音量を調整します。0 〜 +6 dB。ダブルクリックで 0 dB。左右（L/R）のメーターが付きます。
- 設定でマスターリミッターを入れておくと、音割れを防ぎます（8.1）。リミッターが働いたかは TopBar の CLIP / GR で分かります。

### 5.9 ヘッドホン（HP LEVEL / HP MIX）

| つまみ | 内容 |
|---|---|
| HP LEVEL | ヘッドホンの音量（0〜2、初期値 1） |
| HP MIX | ヘッドホンで聴く音の割合。左いっぱいで CUE だけ、右いっぱいで MASTER だけ。初期値は中央（0.5） |

- ヘッドホンの出力がないときは「⚠ No headphone output (channels 3-4)」と出ます。

## 6. Beat FX

曲の拍に合わせてかかるエフェクトです。BEAT FX 1 と 2 の 2 台があります。

| 項目 | 内容 |
|---|---|
| Type（種類） | ECHO（やまびこ）／ REVERB（残響）／ FLANGER（うねり）／ FILTER |
| Beats（拍数） | ◀ ▶ で 1/16・1/8・1/4・1/2・3/4・1・2・4・8・16・32・64 から選ぶ。エフェクトの周期の長さ |
| MIX（量） | かかり具合（wet/dry）。初期値 50%、5% ずつ |
| Target（対象） | A / B / M（マスター全体）を選ぶ |
| BPM 表示 | エフェクトの基準にしている BPM |
| ON / OFF | エフェクトの入／切 |

## 7. 録音

ミックスの最終出力（MASTER の音）を、WAV ファイルに録音します。

| 項目 | 内容 |
|---|---|
| 開始／停止 | TopBar の ● REC、または Ctrl+R |
| 保存先 | ドキュメントフォルダの `KIZAMI DJ\Recordings\` |
| ファイル名 | `YYYYMMDD-HHMMSS.wav`（例：20261022-213045.wav）。同じ名前があるときは `-2`、`-3` を付けて上書きしない |
| 形式 | WAV（24bit） |
| 録音中の表示 | REC ボタンに経過時間 |
| 停止したとき | 「Recording saved」と保存先が出る |

- 書き込みが追いつかず音が欠けたときは、「⚠ Dropped {x}」が出ます。
- 書き込みに失敗すると、赤いバナー「Recording stopped: ...」が出て、そこまでの録音がファイルに残ります。バナーは **[Close]** で消します。
- ドキュメントフォルダを OneDrive などへ移している場合も、そちらの中の `KIZAMI DJ\Recordings\` に保存されます。
- 録音できる最大の長さ・ファイルのサイズ上限は未確認です。

## 8. 設定

右上の **⚙** で開きます。Esc で閉じます。「General」「Shortcuts」「MIDI」の 3 つのタブがあります。

### 8.1 General タブ

#### 出力

| 項目 | 内容 |
|---|---|
| Output device | 音を出す機器。「Default device」「{name} (default)」「{name} (not found)」から選ぶ |
| Current: ... | 使っているデバイス・チャンネル数・バッファの大きさ |
| Auto gain (match track loudness to −14 LUFS) | 曲の音量を −14 LUFS に揃える（初期は入） |
| Master limiter (prevents clipping) | 音割れを防ぐ（初期は入） |
| Crossfader curve | Smooth（なめらか。初期）／ Cut（端から少し動かすだけで反対側が全開になり、端でだけ切れる。スクラッチ向き） |

- チャンネル数が 4 未満のときは、「Headphone output requires a 4-channel device (currently Master only)」と出ます。

#### ライブラリのフォルダ（Library folders）

- 登録済みのフォルダの一覧。各行の **[Remove]** を押し、確認の **[Really remove]** を押すと外れます（曲のファイルは消えません）。
- **[Add folder]** で追加します。

#### 拍の解析（Beat analysis）

- 「Using Beat This! (AI beat detection).」または「Using the simple estimator.」が出ます。簡易のときは、AI を使えない理由も出ます。
- モデルのフォルダは **[Choose folder]** で指定し、**[Reset to default]** で戻せます。

### 8.2 Shortcuts タブ

- 操作の行の **[Change]** を押してから、割り当てたいキーを押します。Esc で取りやめ。
- 使えるキー：キー単独、または Shift+キー、Ctrl+キー。Hot Cue は修飾キーなしのキーだけ（Shift+キーは削除に使われるため）。
- すでに使われているキーを選ぶと「{combo} is already used by {name}. Swap them?」と出ます。**[Swap]** か **[Cancel]** を選びます。
- 各行の **[Reset]** と、全体の **[Reset all to default]** があります。
- 割り当てられないキー：Tab・Escape・CapsLock・NumLock・かな・修飾キー単独・Alt や Win との組み合わせ・Shift+Ctrl の同時・Ctrl+C/V/X/A/Z/Y。テンキーの数字は Hot Cue に割り当てられず、Shift とも組み合わせられません。
- キーの表示は、US 配列のキーボードの刻印表記です（例：-、=、`、'、¥、Ro、Numpad1）。日本語配列（JIS）の刻印とは異なる場合があります。

### 8.3 MIDI タブ

MIDI コントローラーを使う設定です。対応機器と操作表は 9 章を見てください。

#### 機器と割り当て

- つないだ MIDI 機器の一覧が出ます。つないですぐは出ないことがあるので、少し待ってください。
- 機器ごとの状態：「Connected」「Not connected」「Cannot open (another app may be using it)」。
- **Mapping** の選択で、その機器に使う割り当てを選びます。「No mapping」（割り当てなし）も選べます。まだ実機で確認していない割り当ては「Untested」と表示されます。
- 下の表に、その割り当ての Action（操作）/ MIDI / Type（種類。Button・Knob・Jog・14-bit）が出ます。MIDI 欄は「Note ch0 #11」（ノート。チャンネル 0・番号 11）、「CC ch0 #20」（コントロールチェンジ。チャンネル 0・番号 20）、「14bit CC ch0 #msb/lsb」のように、種類・チャンネル・番号の順に出ます。
- 割り当てに読めない行があるとき、「⚠ ...」の行が出ます。割り当てそのものが読めないときは「Could not read this mapping: ...」と出ます。
- 状態が変わると、画面に「MIDI device connected: {name}」「MIDI device disconnected: {name}」「Cannot open MIDI device: {name}」と出ます。

#### MIDI Learn（自分でボタンを割り当てる）

画面の部品とコントローラーのつまみ・ボタンを、自分で対応づける機能です。

1. **[Start Learn]** を押す。
2. 「Click the control you want to assign (Esc to exit)」――画面の部品（ボタン・つまみなど）をクリックする。
3. 部品に複数の操作があるときは、「Which action do you want to assign?」と出るので選ぶ。
4. 「{action}: Move a control on your controller」と出る。動かしたいつまみやボタンを操作する。**[Cancel]** で取りやめ。
5. すでに別の操作に割り当て済みなら、「{midi} is already assigned to {action}. Replace it?」と出る（{midi} は「Note ch0 #11」などの形）。**[Replace]** か **[Keep]**。
6. 「{midi} assigned to {action}.」と出る。種類（Button・Knob・Jog・14-bit）が表示される。**[Redo]** か **[Next control]**。
7. メッセージが届かないと「No message received.」と出る。**[Try again]** か **[Cancel]**。

- Learn 中は、割り当てできる部品に枠が付きます。TopBar の **[Exit]** か Esc で終わります。

#### ジョグ（スクラッチとピッチベンド）

- ジョグの上面に触れて回す：スクラッチ（レコードを手で動かすように音が前後する）。1 回転で 1.8 秒ぶん進みます。
- 触れずに回す（側面や上面）：ピッチベンド（速さを一時的にずらして、拍を合わせる）。1 秒に 1 回転で +5%、最大 ±10%。回すのをやめると約 0.1 秒で 0 に戻ります。量は「BEND +x.x%」と出ます。

### 8.4 バナー・通知・警告の意味と対処

#### バナー（画面上部の赤い帯）

| 表示 | 意味 | 対処 |
|---|---|---|
| Audio output: {device} was disconnected / Reconnecting to the same device | 音の出力機器が外れた | つなぎ直すと再生位置を保って再開する。戻らなければ設定で別のデバイスを選ぶ |
| Output lost（エラーと対処が出る） | 出力が止まった | 表示の対処に従う。直らなければ KIZAMI DJ を再起動 |
| Recording stopped: ... | 録音の書き込みに失敗 | そこまでの録音は表示のパスに残る。空き容量・保存先を確かめる。**[Close]** で消す |

#### 通知（画面に数秒出るメッセージ）

通知は 6 秒で消えます（エラーは閉じるまで残ります）。最大 4 件まで表示します。

| 表示 | 意味 |
|---|---|
| Importing {folder} / Import finished / Import cancelled | 3.1 |
| Automatic analysis stopped / {n} analyses timed out | 3.6 |
| {saved device} not found. Playing through the default device | 前回の出力機器が見つからず、既定のデバイスに切り替えた。設定で選び直せる |
| Recording saved | 7 章 |
| MIDI device connected / disconnected: {name}、Cannot open MIDI device: {name} | 8.3。「Cannot open」は他のアプリが使っていないか確かめる |
| Mapping {name} has lines that could not be read | 8.3。読めない行は使われない |

#### 復元の画面（起動時）

- 「The library database is corrupted」：戻すバックアップ（新しい順）を選び、**[Restore and start]**。やめるときは **[Quit]**。バックアップが無いときは「No backups are available to restore.」と出ます。
- 「KIZAMI DJ could not start」：**[Start again]** か **[Quit]**。
- この画面は Esc では閉じません。

#### エラーの対処ヒント（画面に出る文）

| 状況 | 出る案内 |
|---|---|
| ライブラリが使用中 | KIZAMI DJ がもう 1 つ起動していないか確かめる |
| ライブラリが新しいバージョンのもの | 新しいバージョンの KIZAMI DJ で開く |
| 曲ファイルを読めない | 移動・削除されていないか、他のアプリが使っていないか、権限を確かめる |
| 対応していない形式 | MP3・AAC（M4A）・FLAC・WAV・AIFF・ALAC が対応 |
| 曲が壊れている | 他のプレイヤーで再生できるか確かめる |
| 曲が長すぎる | 読み込めない（上限の長さは未確認） |
| メモリ不足 | 他のアプリを閉じてから、もう一度読み込む |
| 出力機器が見つからない | 機器の接続と電源を確かめるか、設定で別の出力デバイスを選ぶ |
| 内部エラー | KIZAMI DJ を再起動。続くときは開発者に知らせる |

- Cue と Hot Cue は、押している間だけ鳴り、キーを離すと止まるホールド式です。
- 文字を入力している間は、ショートカットは効きません（Ctrl を使うものは除く）。
- Ctrl+R と Ctrl+F は、画面の再読み込みやブラウザの検索ではなく、KIZAMI DJ の機能として動きます。
- 曲が載っていないデッキでは何も起きません。拍の解析がない曲では SYNC・ループ・Beat Jump も効きません。
- キーの Beat Jump の拍数は、画面で選んだ値を使います（4.6）。

## 11. 困ったとき・用語集

### 11.1 困ったとき

| 症状 | 確かめること |
|---|---|
| 音が出ない | ① 設定の出力デバイスが正しいか ② デッキの PLAY が押されているか ③ VOL フェーダー・MASTER が下がっていないか ④ クロスフェーダーが反対側に寄っていないか ⑤ EQ の KILL が入っていないか ⑥ FILTER が端まで回っていないか ⑦ 赤いバナー（出力の切断）が出ていないか |
| ヘッドホンで聴けない | 出力機器が 4ch か（設定の「Current: ...」でチャンネル数を確認）。2ch のときは CUE が使えない。HP LEVEL・HP MIX も確認 |
| 音が途切れる | TopBar の CPU バー・⚠ n を見る。高いときは他のアプリを閉じる。出力デバイスのバッファの大きさは設定の「Current: ...」で確認できる（変更方法は未確認） |
| 音が割れる | MASTER・チャンネル VOL を下げる。マスターリミッターを入れる。メーターが赤くならないようにする |
| SYNC・ループ・Beat Jump が使えない | 曲に拍の解析がない（4.8）。ライブラリで **[Re-analyze]** |
| 解析が終わらない／失敗する | 3.6。**[Re-analyze]**。曲の形式が対応しているか（1.2）確かめる |
| 曲が「(missing)」と出る | ファイルを元の場所に戻すか、フォルダを登録し直す |
| 曲を読み込めない | 8.4 のエラー対処の表 |
| MIDI 機器が出ない／警告が出る | ① ケーブルと電源 ② 少し待つ ③ 他のアプリが MIDI ポートを使っていないか（Windows は 1 つのアプリだけ） ④ 割り当てを選び直す |
| MIDI で一部の操作だけ動かない | 古い割り当てファイルが残っていないか（9.3 の注意） |
| 起動できない | 8.4 の復元の画面に従う |
| ★が付かない | 3.7 の「★が付かない場合」 |
| 録音が止まった | 7 章。バナーに出るパスに、そこまでの録音が残る |
| 不具合を知らせたい | 設定の **[Open logs folder]** で、動作の記録（`kizamidj.日付.log`）のフォルダが開く。新しい 7 日分だけが残り、曲名やファイルの場所は書き込まれない。最新のファイルを添えて知らせる。詳しく調べるときは、環境変数 `KIZAMIDJ_LOG=debug` で起動すると、曲の場所を含む細かい記録が出る（共有する前に中身を確かめる） |

### 11.2 用語集

| 用語 | 意味 |
|---|---|
| BPM | 1 分間の拍の数。曲の速さの単位 |
| Camelot（キャメロット） | 曲のキー（調）を 1A〜12B で表す記法。隣り合うキーは合わせやすい（3.7） |
| 拍のグリッド（ビートグリッド） | 曲の拍の位置を示す目盛り。SYNC・ループ・Beat Jump の土台 |
| デッキ | 曲を再生する 1 台のプレイヤー |
| ミキサー | 2 つのデッキの音量や音色を調整して混ぜる機器（画面） |
| マスター | BPM とキーの基準にするデッキ。または最終出力 |
| SYNC（シンク） | 2 台のデッキの BPM（と拍）を揃える機能 |
| CUE（キュー） | ①曲の頭出しの位置、またはそこへ戻る操作 ②ミキサーの CUE ボタン：その音をヘッドホンで聴く |
| Hot Cue | 好きな位置に付ける印。ボタンで即ジャンプできる |
| ループ | 一部の区間をくり返し再生すること |
| Beat Jump | 拍の単位で前後へ飛ぶ操作 |
| スクラッチ | レコードを手で前後させたように、音を前後に動かす演奏 |
| ピッチベンド | 速さを一時的にずらして、2 曲の拍を手で合わせる操作 |
| KEYLOCK | テンポを変えても音の高さを変えないこと |
| TRIM | 入力段の音量。曲ごとの音量差を揃える |
| オートゲイン | 曲の音量を自動で −14 LUFS に揃える機能 |
| LUFS | 人の耳に聞こえる音量の単位 |
| EQ（イコライザー） | 高音・中音・低音を個別に上げ下げする機能 |
| KILL（キル） | 帯域を完全に切ること |
| FILTER | 低音または高音を削る機能（LPF / HPF） |
| LPF / HPF | ローパス（高音を削る）／ ハイパス（低音を削る） |
| クロスフェーダー | A と B の音量を 1 本の横フェーダーで切り替える |
| リミッター | 設定した音量を超えないよう自動で抑え、音割れを防ぐ機能 |
| Beat FX | 拍に合わせてかかるエフェクト（ECHO・REVERB・FLANGER・FILTER） |
| MIDI | 楽器・コントローラーとパソコンをつなぐ通信の規格 |
| MIDI Learn | コントローラーのつまみやボタンを、画面の部品に自分で割り当てる機能 |
| ジョグ | コントローラーの回転盤。スクラッチやピッチベンドに使う |
| アンダーラン | 音の処理が間に合わず、音が途切れること |
| Beat This! | 拍を推定する AI のモデルの名前 |
